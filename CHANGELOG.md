# Changelog

## 1.0.1 — prepared 17 October 2026

This is a visual revision of the software displays. No archive DOI has been assigned to this edition.

- Updated the six main and two supplementary figure renderers to black regular text, centered regular subpanel titles, bold 13 pt panel letters and a minimum native text size of 10 pt. Original workflow icons and figure spacing were revised for the current article displays.
- Added editable SVG export alongside vector PDF and 600 dpi PNG for all eight displays.
- Preserved the scientific inputs, aggregate numerical results and the 378-value main, 376-value supplementary and five-value Figure 3 context ledgers. Scientific calculation formulas and retained-artifact replay semantics are unchanged; this visual revision introduces no model fitting or training.
- Refreshed source bindings and the closed release inventory, and updated version metadata while preserving software, data and upstream license distinctions.
